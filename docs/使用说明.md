# 新点OA周例会自动化 — 使用说明

适用脚本：`oa-weekly-meeting.user.js`（当前版本 1.6.1）
适用系统：新点 OA（`oa.epoint.com.cn/epointoa9`，会议看板 = 统一会议 / 我的会议）
作用：一键创建部门周例会草稿 —— 填会议名称与形式、按姓名选择参会/列席人员、新增议题，最后保存为草稿。

---

## 一、安装

1. 浏览器安装 **篡改猴（Tampermonkey）** 扩展（Chrome / Edge 均可）。
2. 安装脚本，二选一：
   - **拖拽**：把 `oa-weekly-meeting.user.js` 拖到浏览器窗口，篡改猴会弹出安装页 → 点「安装」；
   - **手动**：点篡改猴图标 → 「添加新脚本…」→ 全选删除模板内容 → 粘贴脚本全部内容 → `Ctrl+S`（macOS 为 `⌘S`）保存。
3. 确认脚本开关为**已启用**。

> 脚本只在 OA 首页（`.../themes/aide/aide?...`）生效，其它页面不加载。

---

## 二、首次使用

1. 先登录 OA，并停留在 OA 首页（标签页保持打开）。
2. 点浏览器工具栏的**篡改猴图标** → 菜单「**立即执行创建周例会**」。
3. 弹出「📋 周例会配置确认」对话框，核对下面几项后点「**确认执行**」：

| 字段         | 说明                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------- |
| 会议日期     | 默认下一个周四，可改；改动后会议名称与期次会自动跟着变                                   |
| 会议期次     | 按脚本内置基准推算的默认值，可手改                                                       |
| 会议名称     | 按 `部门-组周例会-年份第N期-MMDD` 生成，可手改                                           |
| 会议形式     | 线上会议（默认）/ 线下会议；选线下时不写入腾讯会议信息                                   |
| 腾讯会议信息 | 线上会议时，这段文字会追加到「议题内容」里                                               |
| 议题名称     | 默认「本周工作情况同步」                                                                 |
| 参会人员     | 姓名列表，多人用 `、` 或逗号分隔（写入时按姓名去 `CONFIG.participantGuids` 取人员 GUID） |     |

**配置会被记住**：点「确认执行」后，上述内容（除日期/期次）保存到本地，下次打开对话框自动带出。需要恢复内置默认值：菜单「重置本地配置」。首次使用会有一条黄色提示条，之后不再显示。

**人员离职**：只从 `participants` 删名字可能不生效——对话框带出的是本地记住的那份旧名单。把离职人员写进 `CONFIG.departedParticipants`，代码名单和记住的旧名单都会被自动剔除，执行日志会打印「参会人员名单中已剔除离职人员: XXX」（v1.6.1 起）。

4. 脚本开始执行，右上角会出现进度提示；跑完弹出「执行成功/失败」面板，面板里同时列出最近日志。

---

## 三、执行过程与结果确认

脚本按 7 步执行：验证页面 → 打开会议看板 → 点「新增会议」→ 填写会议信息 → 选择参会/列席人员 → 新增议题 → 保存草稿。

**跑完后请到「我的会议 → 会议列表（草稿）」核对 4 处**：

1. 会议名称、会议日期、会议形式、会议室；
2. **参会人员（有表决权）** 与 **列席人员（无表决权）** 是否都是你配置的那批人；
3. 议题名称与议题内容；
4. 线上会议时，议题内容里是否带上了腾讯会议信息。

> 说明：脚本会先在 OA 人员弹窗里按姓名勾选，再把结果同步到「参会人员」「列席人员」两行，保证两边名单一致。

## 四、菜单命令

| 菜单                           | 用途                                 |
| ------------------------------ | ------------------------------------ |
| 立即执行创建周例会             | 打开配置对话框并执行完整流程         |
| 查看执行状态                   | 查看是否在执行、执行到第几步         |
| 查看执行日志                   | 弹出最近 20 条日志（排障用）         |
| 清除运行锁（卡在"执行中"时用） | 脚本异常中断后一直提示"执行中"时清锁 |
| 重置本地配置（恢复内置默认值） | 清掉记住的配置，回到脚本内置默认值   |

## 五、常见问题

**Q1. 提示"脚本正在执行中"，但我没有在跑？**
菜单点「清除运行锁」。脚本也有 2 分钟超时自动解锁。

**Q2. 某个步骤报"未找到元素 / 超时"？**
多半是 OA 页面结构或会议模板变了。先用「查看执行日志」看失败步骤与诊断信息，再对照脚本第 5 节「适配」调整选择器或模板配置。

**Q3. 人员没写上 / 只写上了一部分？**
脚本按「姓名 → 人员 GUID」映射写入参会/列席人员，日志会打印 `已写入人员字段 seatnames（N 人）` 与回读值：

- 如果提示"取不到 GUID"，说明 `CONFIG.participantGuids` 里缺这个人的 GUID，补上即可；
- **怎么拿 GUID**：在 OA「新增会议」页手动打开一次人员选择弹窗、勾选该人员并确定，然后用浏览器控制台读取该字段的隐藏值：
  ```javascript
  // 在会议新增页所在的 iframe 控制台里执行
  document.getElementById("seatnames$value").value;
  ```
  输出的 GUID 列表按顺序对应姓名列表，把姓名和 GUID 补进 `CONFIG.participantGuids`。
- 姓名要和 OA 通讯录**完全一致**（含异体字；脚本里对「曹渝澄 / 曹倢澄 / 曹俞澄」做了别名兼容，其它同音字请在代码 `altNameMap` 里补）。

**Q4. 议题名称在草稿里是空的？**
议题编辑页会异步回填表单，脚本已做"写入 → 回读 → 被覆盖就重写"（日志会打印 `议题字段回填`）。若仍为空，请把日志发出来。

**Q5. 换人 / 换会议室 / 换模板怎么办？**
见下面「六、给其它团队适配」。

## 六、给其它团队适配

只有 **同一套 OA**（域名、版本一致）才能直接复用选择器，需要改的内容都集中在脚本顶部 `CONFIG`：

| CONFIG 项                          | 说明             | 举例                                              |
| ---------------------------------- | ---------------- | ------------------------------------------------- |
| `urls.oaHome` 与文件头 `@match`    | OA 首页地址      | 域名/版本不同时要一起改                           |
| `meeting.nameTemplate`             | 会议名称格式     | `研发4部-1组周例会-{year}年第{period}期-{mmdd}`   |
| `meeting.type`                     | 会议类型         | `0203`（基层合伙单元会议）                        |
| `meeting.modelGuid`                | 会议模板 GUID    | 模板换了要更新（可从新增会议页的 `modelguid` 取） |
| `meeting.period.base` / `baseDate` | 期次推算基准     | 以某天为第 N 期，之后每周 +1                      |
| `meeting.tencentMeeting`           | 腾讯会议信息模板 | 主题/时间/链接/会议号/邀请人                      |
| `participants`                     | 参会人员姓名     | 换团队改这里                                      |
| `participantGuids`                 | 姓名 → 人员 GUID | 与 `participants` 配套，缺的按 FAQ Q3 补上        |
| `departedParticipants`             | 已离职人员姓名   | 人员离职登记到这里，脚本会自动从名单中剔除        |
| `agenda.name` / `label`            | 议题名称 / 标签  | `1`=ST议题，`2`=AT议题，`0`=其他                  |

改完保存即可；也可不改代码，直接在「周例会配置确认」对话框里改议题与人员（会被记住），但会议名称格式、模板、期次基准这类必须改代码。

**会议室类型**：脚本按当前 OA 的选项定位（`#mini-11$ck$0` 等）；若模板的会议室选项变了，请参考脚本里 `CONFIG.selectors` 与本项目文档同步更新。

## 七、其它

- 日志前缀统一为 `[OA-Weekly]`，可在浏览器控制台按该关键字过滤。
- 脚本只做"新增 + 保存草稿"，不会发送会议通知；请在草稿确认无误后再手动提交。
- 遇到问题请把这三样发出来：**脚本版本号**（日志首行 `v1.6.1`）、**执行日志**（菜单「查看执行日志」）、**当前页面截图**。
