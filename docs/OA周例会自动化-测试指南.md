# 新点OA周例会自动化 - 测试指南

## 一、测试环境准备

### 1.1 基础环境

| 项目 | 要求 | 说明 |
|------|------|------|
| 操作系统 | Windows 10/11 或 macOS | 任意支持浏览器的操作系统 |
| 浏览器 | Chrome 120+ 或 Edge 120+ | 推荐 Chrome，兼容性最佳 |
| Tampermonkey | v5.0+ | 需从官方商店安装 |
| 网络 | 内网可访问 oa.epoint.com.cn | OA 系统通常部署在内网 |
| OA 账号 | 有效的 OA 账号 | 需提前登录获取 Cookie |

### 1.2 文件清单

| 文件 | 用途 | 使用顺序 |
|------|------|---------|
| `oa-weekly-meeting-validator.user.js` | 技术验证脚本（先安装） | 第一步：验证页面结构和选择器 |
| `oa-weekly-meeting.user.js` | 完整功能脚本 | 第二步：确认选择器正确后，安装完整脚本 |

### 1.3 安装步骤

**第一步：安装 Tampermonkey**

1. 打开 Chrome 浏览器
2. 访问 Chrome 应用商店搜索 Tampermonkey
3. 点击"添加至 Chrome"
4. 确认安装

**第二步：安装自动化脚本**

1. 点击浏览器工具栏的 Tampermonkey 图标
2. 选择"添加新脚本"
3. 复制脚本全部内容
4. 粘贴到编辑器中
5. 按 `Ctrl+S` 保存
6. 确认脚本已启用（开关为绿色）

**第三步：验证 OA 登录**

1. 访问 `https://oa.epoint.com.cn/epointoa9/frame/fui/pages/themes/aide/aide?pageId=aide`
2. 手动登录 OA 系统（扫码或账号密码）
3. 确认登录成功后能看到 OA 主页

| 项目 | 内容 |

| **前置条件** | 无 |

| **测试数据** | 见下表 |
| **预期结果** | 返回正确的 ISO 周数 |

| 输入日期 | 预期周数 | 说明 |
|---------|---------|------|
| 2026-01-01 | 1 | 新年第一天 |
| 2026-01-04 | 1 | 第一个周四（ISO 标准：周四在哪天，该周就算哪一年） |
| 2026-09-17 | 38 | 当前日期 |
| 2026-12-31 | 1 | 跨年周（下一年的第 1 周） |
| 2024-12-30 | 1 | 2024 年最后一天属于 2025 年第 1 周 |

## 六、问题排查指南

### 6.1 常见问题速查

| 现象 | 可能原因 | 排查方法 | 解决方案 |
|------|---------|---------|---------|
| 脚本不执行 | Tampermonkey 未启用脚本 | 点击 Tampermonkey 图标，确认脚本开关为绿色 | 启用脚本 |
| 脚本不执行 | `@match` 不匹配当前 URL | 检查脚本元数据中的 `@match` | 修改 `@match` 或访问正确的 URL |
| 脚本不执行 | 页面 CSP 阻止注入 | Console 显示 CSP 相关错误 | 改用 Chrome 插件方案 |
| 脚本不执行 | `autoRun` 设为 `false` | Console 显示"自动执行已禁用" | 正常行为，需通过菜单手动触发 |
| 在步骤 1 停止 | Cookie 过期/未登录 | 手动访问 OA，确认是否需要重新登录 | 重新登录后刷新 |
| 步骤 1 停止且提示"执行中" | 脚本上次异常退出，锁未释放 | 等待 2 分钟锁超时自动清理 | 或用 Console 手动清理（见应急处理） |
| 元素找不到 | 页面结构变化 | 查看 Console 输出的页面结构信息 | 更新选择器 |
| 元素找不到 | 元素在 iframe 中 | Console 显示 iframe 信息 | 验证脚本已包含 iframe 回退逻辑 |
| 点击无效果 | 元素被遮挡或不在视口 | 检查 Console 输出的元素位置信息 | `safeClick` 已包含 scrollIntoView |
| 人员选择失败 | 人员树在 iframe 中 | Console .Debugf 显示 "iframe 访问跳过" | 检查 iframe 是否跨域 |
| 保存失败 | 表单验证不通过 | 检查所有必填项是否填写 | 检查会议名称格式 |
| 保存失败 | 登录态过期 | 检查是否有跳转到登录页 | 重新登录 |
| 会议室选择无效 | mini-ui 组件未正确响应 | 检查是否操作了真实 `<input>` | 脚本已使用 `input[type="checkbox"]` 选择器 |

### 6.2 调试技巧

**技巧 2：监听控制台的所有 console.log**

**技巧 3：断点调试**

**技巧 4：网络请求监控**

**技巧 5：DOM 快照**

### 6.3 应急处理

如果脚本运行中出现异常，按以下步骤处理：

1. **立即停止脚本**：关闭当前标签页或刷新页面
2. **检查当前状态**：手动查看 OA 页面，确认当前操作到哪里了
3. **清理锁状态**：如果提示"脚本正在执行中"但实际未执行，在 Console 中执行：
   ```javascript
   GM_setValue('oa_running', false);
   GM_setValue('oa_step', 0);
   ```
   或等待 2 分钟让锁超时自动清理
4. **手动完成**：根据 Console 日志，从失败的步骤手动继续
5. **记录问题**：将错误日志和截图保存，用于后续修复
