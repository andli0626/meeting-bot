# 新点 OA 周例会自动化（油猴脚本）

> 一键在新点 OA 中创建部门周例会草稿：自动填写会议信息、按姓名选择参会/列席人员、新增议题，并保存为草稿。

- **脚本**：`code/oa-weekly-meeting.user.js`（当前版本 1.6.1）
- **适用系统**：新点 OA `oa.epoint.com.cn/epointoa9`（统一会议 / 我的会议）
- **加载范围**：仅在 OA 主页（`.../themes/aide/aide?...`）生效，其它页面不加载
- **运行环境**：安装 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴）扩展的 Chrome / Edge 浏览器

---

## 功能特性

- **一键创建**：从打开会议看板到保存草稿全自动，共 7 步
- **智能推算**：自动推算下一个周四、会议期次，按模板生成会议名称
- **人员选择**：按姓名去 OA 人员弹窗勾选参会 / 列席人员，并同步回写两个字段
- **配置记忆**：会议名称、形式、议题、人员等配置会被记住，下次自动带出
- **菜单命令**：支持「立即执行 / 查看状态 / 查看日志 / 清除运行锁 / 重置配置 / 诊断表单」
- **执行反馈**：右上角实时进度提示，完成后弹出结果面板与最近日志
- **团队可复用**：换团队 / 换模板只需改脚本顶部 `CONFIG`，无需改流程

## 安装

1. 浏览器安装 **Tampermonkey（篡改猴）** 扩展
2. 安装脚本（二选一）：
   - **拖拽**：把 `code/oa-weekly-meeting.user.js` 拖到浏览器窗口 → 在弹出页点「安装」
   - **手动**：点篡改猴图标 → 「添加新脚本…」→ 全选删除模板 → 粘贴脚本全部内容 → `Ctrl+S`（macOS `⌘S`）保存
3. 确认脚本开关为 **已启用**

> 图文安装步骤见 [脚本安装.mp4](脚本安装.mp4) 与 [前提：先安装油猴插件（推荐Edge浏览器）.png](前提：先安装油猴插件（推荐Edge浏览器）.png)。

## 快速开始

1. 先登录 OA，并停留在 **OA 主页**（标签页保持打开）
2. 点浏览器工具栏的 **篡改猴图标** → 菜单「**立即执行创建周例会**」
3. 在「📋 周例会配置确认」对话框核对以下字段，再点「**确认执行**」：

| 字段         | 默认值                               | 说明                                       |
| ------------ | ------------------------------------ | ------------------------------------------ |
| 会议日期     | 下一个周四                           | 改动后会议名称与期次自动跟着变             |
| 会议期次     | 按基准推算                           | 可手改                                     |
| 会议名称     | `部门-组周例会-年份第N期-MMDD`       | 可手改                                     |
| 会议形式     | 线上会议                             | 线下会议时不写入腾讯会议信息               |
| 腾讯会议信息 | 主题 / 时间 / 链接 / 会议号 / 邀请人 | 线上会议时追加到「议题内容」               |
| 议题名称     | 本周工作情况同步                     | 可手改                                     |
| 参会人员     | 姓名列表（`、` 或逗号分隔）          | 按姓名去 `CONFIG.participantGuids` 取 GUID |

4. 脚本开始执行，右上角显示进度；完成后弹出「执行成功 / 失败」面板
5. 到 **我的会议 → 会议列表（草稿）** 核对会议名称、日期、人员、议题

> 完整使用说明、菜单命令、常见问题、其它团队适配见 [docs/使用说明.md](docs/使用说明.md)。

## 菜单命令

| 菜单                           | 用途                                   |
| ------------------------------ | -------------------------------------- |
| 立即执行创建周例会             | 打开配置对话框并执行完整流程           |
| 查看执行状态                   | 查看是否在执行、执行到第几步           |
| 查看执行日志                   | 弹出最近日志（排障用）                 |
| 清除运行锁（卡在"执行中"时用） | 脚本异常中断后一直提示「执行中」时清锁 |
| 重置本地配置（恢复内置默认值） | 清掉记住的配置，回到脚本内置默认值     |
| 诊断会议表单                   | 打开表单转储字段后关闭，不产生草稿     |

## 配置说明

所有可配置项都集中在脚本顶部 `CONFIG`，换团队 / 换环境改这里即可：

| CONFIG 项                           | 说明                       |
| ----------------------------------- | -------------------------- |
| `urls.oaHome` / 文件头 `@match`     | OA 地址                    |
| `meeting.nameTemplate`              | 会议名称格式（部门、组名） |
| `meeting.type` / `modelGuid`        | 会议类型 / 会议模板 GUID   |
| `meeting.period.base` / `baseDate`  | 期次推算基准               |
| `meeting.tencentMeeting`            | 腾讯会议信息模板           |
| `participants`                      | 参会人员姓名               |
| `participantGuids`                  | 姓名 → 人员 GUID 映射      |
| `departedParticipants`              | 已离职人员（自动从名单剔除） |
| `agenda.name` / `label` / `content` | 议题名称 / 标签 / 内容     |

> 详细字段含义与其它团队适配见 [docs/使用说明.md#六、给其它团队适配](docs/使用说明.md#六给其它团队适配)。

## 常见问题

- **提示「脚本正在执行中」但没在跑**：菜单点「清除运行锁」；脚本也有 2 分钟超时自动解锁。
- **某步骤报「未找到元素 / 超时」**：OA 页面结构或会议模板变了，用「查看执行日志」看失败步骤，再对照脚本选择器调整。
- **人员没写上 / 只写上一部分**：补全 `CONFIG.participantGuids` 里的姓名 → GUID 映射；GUID 可从 OA 人员弹窗的 `#seatnames$value` 隐藏值读取。
- **人员离职后还出现在会议里**：把姓名登记到 `CONFIG.departedParticipants`，代码名单和配置对话框里记住的历史名单都会自动剔除。
- **议题名称在草稿里是空的**：脚本已做「写入 → 回读 → 被覆盖就重写」，仍为空请把日志发出来。

更多 FAQ 见 [docs/使用说明.md#五、常见问题](docs/使用说明.md#五常见问题)。

## 排障信息收集

遇到问题请提供以下三样，便于快速定位：

1. **脚本版本号**：日志首行（如 `v1.6.1`）
2. **执行日志**：菜单「查看执行日志」
3. **当前页面截图**

日志前缀统一为 `[OA-Weekly]`，可在浏览器控制台按该关键字过滤。

---

## 注意事项

- 脚本只做 **新增 + 保存草稿**，不会发送会议通知；请在草稿确认无误后手动提交。
- 会议名称格式固定为 `{部门}-{组}周例会-{年份}年第{期数}期-{MMDD}`。
- 勾选「新增议题」前必须确保会议室已勾选，否则会触发「会议形式验证失败」。
